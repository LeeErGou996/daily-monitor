CPPI Allocation

Current-state allocation calculator. Historical performance is not reapplied to the entered portfolio value.

Methodology and limitation

CPPI sets equity exposure from the cushion: C = V − F and E = min(V, m × C). This page is an allocation calculator, not a guarantee. Discrete rebalancing, jumps, transaction costs, and execution delays can still cause realized value to cross the intended floor.

Methodology and limitation

The required rate solves the standard future-value equation for the remaining trading periods. The solver intentionally accepts annualized rates only within −50% to +200%; values outside that range are reported instead of silently returning a boundary. Historical values use available daily closes, so this is a planning model rather than a real-time forecast.
