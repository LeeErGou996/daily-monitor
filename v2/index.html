CPPI Allocation

Current-state allocation calculator. Historical performance is not reapplied to the entered portfolio value.

Methodology and limitation

CPPI sets equity exposure from the cushion: C = V − F and E = min(V, m × C). This page is an allocation calculator, not a guarantee. Discrete rebalancing, jumps, transaction costs, and execution delays can still cause realized value to cross the intended floor.

Methodology and limitation

Baseline CAGR is the return originally required from the selected start point. Adaptive CAGR recalculates the return required from the latest modeled portfolio value. Funding Ratio is modeled portfolio value divided by the required path value, while Path Gap is their euro difference. Historical values use recorded daily closes, so the modeled portfolio is not the same as a live brokerage balance.
