Definitions
  • Ann. return: geometric, (Vend/V0)252/n−1; extrapolated when the window is shorter than one year.
  • Sharpe: mean daily excess return over the risk-free rate ÷ σ × √252. Sortino uses downside deviation versus the risk-free rate.
  • VaR / CVaR (95%): historical one-day loss at the 5th percentile and the mean loss beyond it.
  • Calmar: annualized return ÷ |max drawdown|. Beta/Alpha: OLS of daily excess returns versus the benchmark; alpha annualized. TE: tracking error = σ of active returns × √252; IR = active return ÷ TE.
  • Risk contribution: wi(Σw)i / w′Σw using the sample covariance matrix and current target weights.

Methodology and limitation

CPPI sets equity exposure from the cushion: C = V − F and E = min(V, m × C), with no leverage. Allocation calculator uses the value you enter directly. The backtest starts from the full history, applies the exposure rule at each daily close to the portfolio's return series, grows the floor at the risk-free rate, charges the trading cost on every change in equity exposure, and holds the remainder in cash at the risk-free rate. It is an allocation rule, not a guarantee: gap risk, discrete rebalancing, costs and execution delays can push realized value through the floor.

Methodology and limitation

Daily DCA is interpreted as a contribution on every calendar day, including weekends and holidays. Because ETF prices are unavailable on non-trading days, those contributions accumulate and are invested at the next available market close in the historical replay. Baseline CAGR is the return originally required from the selected start point, annualized on a 365.25-day calendar basis. Adaptive CAGR recalculates the return required from the latest modeled portfolio value. Funding Ratio is modeled portfolio value divided by the required path value, while Path Gap is their euro difference. A negative required CAGR means the planned contributions alone are sufficient to exceed the target at a 0% return. Historical values use recorded closes, so the modeled portfolio is not the same as a live brokerage balance.

Monte Carlo: probability of reaching the goal

3,000 paths · lognormal monthly steps · fixed seed
Starts from the latest modeled portfolio value (from the replay above), contributes the daily DCA every calendar day, and draws log-normal monthly returns with the expected return and volatility you enter. The default 7% / 16% is a long-run equity assumption; the sample volatility is measured over a short window and is a poor guide to the future. Not a forecast.
